# AUCB Valuation Report — exact field list

Source of truth: the bank's own blank Excel template ("AUCB_Format.xlsx") and a real
prior report ("AUCB_VALUATION_SIMINA.pdf") for Alleppey Urban Co-operative Bank,
signed by Dhanish Nair (IBBI registered valuer / Chartered Engineer / empaneled
valuer for AUCB). Reproduce this section order and these exact labels — the bank
expects this specific layout, not a generic valuation report shape.

## Header block
Three-column band: left = valuer credentials ("Dhanish Nair / IBBI registered
valuer / Chartered Engineer / Empaneled valuer for Alleppey Urban Co-operative
Bank"), center = "Valuation Report" title, right = "AUCB / Alleppey Urban
Co-operative Bank".

## 1. Customer Details
1. Branch Name
2. Application Number
3. Date of site visit
4. Date of Report
5. Purpose of Valuation — boilerplate: "To assess the present market value of the property."
6. Name of Customer
7. Contact number of the customer

## 2. Property Details
1. Property Address with Pin code
2. Legal address (survey no., block, village, taluk, district)
3. Landmark
4. Owner Name
5. Type of Property
6. Approved Usage of Property
7. Actual Use of the property
8. Property occupancy Details
9. Name of Person Occupying the property
10. If Rented, Tenant Name & Rent
11. Expected/Rent Received
12. Name & Contact details of person met site
13. Name of House/Door/Society Board
14. Proximity to Civic amenities

## 3. Documents provided for valuation
Table: Document | DOC NO | Dated on — rows for Title deed, Land tax receipt,
Possession certificate, Building tax receipt, Location sketch.

## 4. Land and Building Approval Details
1. Approved plan provided, Yes/No
2. Approved plan number & Date
3. Occupancy Certificate available, Y/N
4. Occupancy Certificate number & Date
5. Approving Authority Name
6. Whether layout plan approved
7. Land classification (e.g. Purayidam / Dryland)

## 5. Boundaries — three separate 4-column tables, same shape
- Boundaries as per Title deed (North/South/East/West)
- Boundaries as per Location sketch (North/South/East/West)
- Boundaries as per Site (North/South/East/West)

## 6. Structural Details
1. Type of Structure (e.g. Load bearing)
2. Type of Roofing & terracing (e.g. RCC)
3. Structure Type with flooring
4. Type of Masonry (e.g. Cement brick)
5. No of Floors
6. Is setback provision done (Front/Side/Rear)
7. Foundation Type (e.g. RR)
8. Age of the property
9. Estimated future life/Residual life
10. Stage of construction-%
11. Quality of Construction
12. Appearance & maintenance of the property
13. Demolition Risk if any with reasons
14. Amenities if any

## 7. Valuation Method
1. Valuation method — usually "Land and Building (Market approach)"
2. Land area (cents/ares)
3. Land value/cent (ongoing rate informed on site)
4. Land value considered (adopted rate)
5. Total land value = land area (cents) × adopted rate/cent
6. Approved built up area and usage
7. Area as per plan (Sq.ft)
8. Area as per site measurement (Sqft)
9. Area as per K-smart (Sqft) — Kerala govt property portal figure, if checked
10. Area considered for valuation (Sqft)
11. Total construction cost of the building = BUA × building rate (new-construction basis)
12. Building value based on current stage = construction cost × (1 − depreciation%)
13. Market value of property = Total land value + Building value based on current stage
14. Govt. Guideline value (Fair Value — see below)
15. **Realizable value of property (85%)** = Market value × 0.85
16. **Distress value of property (75%)** = Market value × 0.75
17. Whether property is in Sensitive Area/Concentrated area (CRZ etc.)
18. Longitude & Latitude of property
19. Whether proper fencing of the Plot is done or not?
20. Width of Road

**Confirmed from a real signed AUCB report**: Realizable = 85% of market value,
Distress = 75% of market value. Don't assume other banks use these same
percentages — this ratio is AUCB-specific, check before reusing structure
for a different bank.

## 8. Remarks
Free-text narrative paragraph(s) summarizing the property, its documents,
land/boundary consistency, and any material caveats. See "Flagging
conventions" below — this is where assumptions and gaps get spelled out in
prose, not just in the table.

## 9. Locality & Marketability of the Property
Single line: Poor / Below Average / Average / Good / Excellent.

## 10. Declaration from the Valuers
Boilerplate:
> I hereby declare that:
> a) Mr. [Valuer name] has personally inspected the property on [date]
> b) The information furnished in my valuation report dated [date] is true
>    and correct to the best of my knowledge and belief and I have made an
>    impartial and true valuation of the property.
> c) I have no direct or indirect interest in the property valued.
> d) Legal documents/aspects fall beyond the scope of valuation.

**Compliance check**: (a) names the IBBI valuer as the one who personally
inspected. Cross-check this against the site inspection form's actual
sign-off name. If an associate engineer did the physical visit (not the
letterhead valuer), reword (a) to say so accurately and flag it for the
valuer's confirmation — don't let the boilerplate silently misstate who
inspected the property.

Followed by Place / Date / Signature line.

## 11. Site Photographs (Annexure)
Grid of captioned site photos (2 per row worked well). Caption by what's
visible (Front Elevation, Gate/Approach, Interior — Room, Interior —
Kitchen, Road Access, etc.), not by filename.

## 12. Google Location Map
Latitude & Longitude, a map link (`https://maps.google.com/?q=<lat>,<lon>`),
and a satellite screenshot if available.

## 13. Fair Value
Govt. Fair Value lookup status — if not independently verified, say so and
point to the Kerala Registration Department portal (igr.kerala.gov.in) with
the survey/village/taluk/district needed to look it up.
